# 常见问题

## 更新后仍显示旧版本

确认 Chrome 扩展卡片加载的是当前仓库的 `src` 文件夹，然后点击“重新加载”。扩展重新加载后必须刷新已经打开的 Higgsfield 标签页。

## `Extension context invalidated`

这是旧页面仍在运行更新前的内容脚本。刷新该 Higgsfield 页面即可。v3.10.6 起会在新脚本启动时清理旧界面残留。

## 字幕按钮无法开启

Chrome 要求标签页录音权限由扩展工具栏图标触发。先播放视频，再点击地址栏右侧的 Higgsfield 扩展图标。启动成功后页面控制条会显示“字幕翻译：开”。

## Apple 本地识别超时

在扩展设置中点击“检测 Apple 本地识别”。如果失败，重新运行 `src/安装Apple本地语音.command`，并在“系统设置 → 隐私与安全性 → 语音识别”中允许 Apple Speech Host。还需要在 macOS 听写语言中安装 English (US)。

## 字幕只有英文

检查“字幕输出”是否设置成“仅英文识别”。该模式用于最低延迟并且不会请求翻译模型。需要中文时改为“仅中文”或“英文先行，随后替换中文”。

## 页面有漏译

选择“全局强制翻译”，再点击“重新扫描”。如果页面刚完成跳转或展开内容，可等待动态扫描后再次执行。图片、视频画面内文字和关闭的 Shadow DOM 不在当前扫描范围内。
