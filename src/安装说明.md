# Higgsfield 中文助手（Chrome 扩展）

## 安装与启动

1. 将 ZIP 解压，保留 `higgsfield-zh` 文件夹，不要删除或移动它。
2. 在 Chrome 地址栏输入 `chrome://extensions`，按回车。
3. 开启右上角「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择 `higgsfield-zh` 文件夹（里面直接能看到 `manifest.json`）。
5. 刷新 Higgsfield 页面。界面词条会自动翻译，包括 About the project → 关于项目。
6. 点击网页右下角「启动引擎」，或点击 Chrome 工具栏中的扩展图标。
7. 在控制台点击「启动本地翻译」，等到显示「本地翻译已启动」。首次需要下载语言包。
8. 保留控制台标签页，切回 Higgsfield。项目介绍等英文正文会自动翻译，后续弹窗、展开内容和页面切换也会继续扫描。

## 使用

- 「恢复原文」暂停翻译并恢复扩展改动过的文字；「显示中文」继续翻译。开关对所有 Higgsfield 标签页生效。
- 「重新扫描」重新尝试未翻译或翻译失败的文字。
- 无需 API Key，无付费翻译接口。本地引擎由 Chrome 提供，必须实际成功启动后才能翻译任意英文正文。
- 推荐使用最新版桌面 Chrome（manifest 最低版本 138）。运行时会检测支持情况，设备、组织策略或语言包下载失败可能导致不可用。
- 关闭控制台标签页会停止新的正文翻译；重新打开控制台并启动即可继续。已翻译文字与内置词条不受影响。
- 建议在 Higgsfield 上关闭其他翻译扩展，避免多个扩展互相改写文字。

## 覆盖与限制

覆盖文本节点、title、placeholder、aria-label、alt；监听页面增删与文字更新，扫描开放的 Shadow DOM，匹配域名下的 iframe。不会因页面标记 notranslate 而跳过项目介绍。保留原有 DOM 节点，不替换整个段落或按钮。

本版面向英文 → 简体中文，不保证其他语种翻译。品牌、用户名、网址、代码块、用户输入内容保留原样。图片内文字、视频画面上的字幕、CSS 生成文字、关闭的 Shadow DOM、外站播放器内容不能通过本版直接翻译。分散在不同文本节点中的句子可能翻译不够连贯。

真实目标页面在制作环境中连接失败，因此尚未验证它在你的登录状态下的实际表现；本地测试使用模拟动态页面及模拟翻译引擎，不能替代实站验收。Chrome 语言包的实际下载与译文质量也需要安装后验证。

## 隐私与权限

仅注入 higgsfield.ai 及其子域名。storage 保存中文开关。页面原文通过 Chrome 内部消息交给本扩展的本地引擎页处理，不发送到第三方翻译服务器；仅内存缓存翻译，不持久保存正文。不读取 Cookie、密码、浏览历史，不访问账户接口。Chrome 首次下载语言包需要网络。

## 排查

- 没有右下角工具条：确认已加载扩展，且刷新了原有网页。
- 只有标题变中文：必须在控制台成功启动本地翻译，并保留该标签页。
- 引擎不可用：更新桌面 Chrome，检查组织策略或下载网络后重试。本版不会偷偷切换至云端服务。
- 漏译：展开内容后点击「重新扫描」。如果是图片或视频里的字，属于本版范围外。
- 网站交互出现异常：点击「恢复原文」并刷新页面；必要时在 Chrome 扩展管理页禁用本扩展。

实现参考：[Chrome Translator API](https://developer.chrome.com/docs/ai/translator-api)、[Chrome 内容脚本](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)。
