HIGGSFIELD · AI 影视知识助手 3.10.2

从看懂项目，到拥有自己的工作流。

中英对照只是入口。助手会提炼 Higgsfield Community Project，并生成可复用、可迁移的专业 AI 影视工作流。

01 / 显示方式

页面翻译

“全局强制翻译”会扫描当前 DOM 中所有英文，并持续处理随后展开或加载的内容；图片和视频画面内文字除外。

02 / 第三方 AI

连接翻译接口

兼容 DeepSeek、OpenAI，以及采用 OpenAI Chat Completions 格式的第三方服务。

开启 AI 后，待翻译文字和术语表会发送到所选服务商。API Key 保存在本机 Chrome 扩展存储中，不写入网页。

视频中文字幕

翻译课程和项目视频

硅基流动 DeepSeek 建议并发量 4；如果频繁出现 429 或频率限制，请降到 2。并发量只影响视频短句，不影响网页翻译和项目分析。

学院播放器封装在应用内部。Apple 模式会在本机听写英文，只把短句交给翻译接口。首次使用请双击插件文件夹中的“安装Apple本地语音.command”，然后在视频播放页点击浏览器右上角的扩展图标。

低延迟模式使用 16 kHz 单声道音频、约 0.32 秒句末停顿和两路并行识别。“仅英文识别”完全不请求大模型；“仅中文”会等译文完成后一次显示，不会中途替换。

03 / Community 学习助手

在项目页面直接提炼

打开 Higgsfield Community 的任意 Project，点击右下角“AI 助手”。可以一键生成项目速读、专业工作流、TapNow 迁移方案，或针对当前项目提问。结果可保存为本地知识卡并导出 Markdown / JSON。

助手优先读取 About the project，同时纳入工具、提示词、制作阶段、失败案例和解决办法。它只分析当前公开展示的项目内容。

04 / 专有名词库

固定译法与保护词

每行一条，格式为“英文 = 中文”。两边写相同内容即可保护品牌、人物名、@标签或模型名不被翻译。

05 / 个人知识库

项目与工作流卡片

在 Community 页面保存的提炼结果会集中在这里；同一项目与分析类型会自动更新，最多保留 100 张。

06 / 本地备用

Chrome 英文 → 简体中文

不发送网页文字，但译文连贯性和术语控制弱于 AI。首次使用可能需要下载语言包；启动后需保留此标签页。

尚未启动。

07 / 应用

让已打开的页面立即更新

可见网页文字、菜单、学院课程、项目说明、评论和提示词代码块都在扫描范围内。视频语音可通过“中文字幕”转写；图片以及视频画面里直接印制的文字暂不识别。
